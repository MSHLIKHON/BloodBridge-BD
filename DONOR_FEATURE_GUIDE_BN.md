# Donor features — version 1.0.0

<!-- File purpose: DONOR FEATURE GUIDE BN documents setup and usage for BloodBridge BD. -->

- একই personal account দিয়ে blood চাওয়া এবং donation enable করা যায়।
- Services → Health Records-এ blood group, donation opt-in, reminder opt-out ও last received date।
- My Donor Profile-এ last donated date, availability ও health declaration।
- Record করা completed donation-এর চেয়ে পুরোনো last date বসানো যাবে না।
- Profile update করলে নতুন screening Pending হয়।
- Private report শুধু তুমি ও consent পাওয়া verified hospital দেখতে পারবে। Seeker, club বা সাধারণ admin raw health report পাবে না।
- Hemoglobin-এর value/unit/test date রাখা যায়; application এটিকে clinical decision হিসেবে ব্যবহার করে না।
- Direct hospital donation ও donor-request commitment একসঙ্গে নেওয়া যাবে না।
- Donation complete হলে history/last date update; direct hospital completion হলে stock-ও একবার বাড়ে।
- 105 দিনের default reminder হলো hospital-এ readiness review করার অনুরোধ। এটি 120 দিনের demo interval বা চিকিৎসকের assessment বাতিল করে না।
- Donor request-এ একবারে 1 unit। একাধিক donor প্রয়োজন হলে আলাদা request।
- Donations এবং blood received history আলাদা। পরিবারের জন্য request করলে নিজের received history বদলাবে না।
