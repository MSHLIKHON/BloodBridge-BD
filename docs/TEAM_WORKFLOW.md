# Team Workflow

## Suggested responsibilities

The team can update these responsibilities according to the actual work completed by each member.

| Area | Example work |
|---|---|
| Frontend | Forms, responsive layout and accessibility |
| Authentication | Registration, login and role permissions |
| Blood requests | Request CRUD and request status |
| Donor module | Search, profile and health information |
| Database and testing | Schema, sample data and XAMPP testing |

## Working agreement

1. Create an issue for a real task.
2. Assign the issue to the member doing the work.
3. Create a short branch such as `feature/donor-validation`.
4. Commit only the files related to that task.
5. Open a pull request and describe what changed.
6. Test login, navigation and database operations before merging.

## Definition of done

- The feature works with XAMPP.
- Existing page navigation still works.
- Forms show understandable validation messages.
- No password or real medical data is committed.
- README or documentation is updated when needed.
