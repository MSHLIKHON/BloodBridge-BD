১. পুরোনো project থাকলে আগে backup

  1. চালু project folder-এর একটি copy রাখুন। phpMyAdmin থেকে existing database Export করুন। Database delete করবেন না।
  2. নতুন ZIP extract করে ভিতরের BloodBridge_BD folder-টি htdocs-এ রাখুন। পুরোনো একই নামের folder থাকলে আগে আলাদা backup নাম দিন।
  3. Nested folder যেন না হয়: htdocs/BloodBridge_BD/setup.php থাকতে হবে, htdocs/BloodBridge_BD/BloodBridge_BD/setup.php নয়।
  4. আগে custom database settings থাকলে config/database.local.php নতুন copy-তে রাখুন। Git repository থাকলে তার history overwrite করবেন না।

২. XAMPP-এ চালান

  1. XAMPP থেকে Apache ও MySQL Start করুন।
  2. Browser-এ http://localhost/BloodBridge_BD/setup.php খুলুন। File double-click করে PHP run হবে না।
  3. নতুন database হলে Install demo database চাপুন। পুরোনো database হলে তার existing Admin email ও password দিয়ে upgrade authorize করুন।
  4. Setup complete হলে User Login অথবা Hospital Login খুলুন।

Apache অন্য port-এ চললে URL-এ সেই port যোগ করুন। Default database bloodbridge_bd, MySQL port 3306, user root, password blank।

৪. নতুন feature কোথায়?

  • Services → Clubs: university club, membership, coordinator ও campaign।
  • Services → Health Records: private reports, consent, reminder preferences ও donation enable।
  • New Request: prescription এবং patient history fields; তারপর authorized review।
  • Services → Hospital Donations: appointment, screening ও one-time donation confirmation।
  • Admin/Hospital Services: prescription review, stock threshold।
  • Admin Services: reports, hospital verification, system settings এবং Testing Centre।

নতুন update: location ও request status

  • Admin-এর New Request এবং request processing নেই; reports ও oversight আছে।
  • Donor/Seeker → Services → My location থেকে address ও optional map pin save করুন। Nearby visibility চালু করতে consent দিন।
  • New Request-এ map point ও prescription দিন। Review হওয়ার পর request খুলে Check Nearby Donors চাপুন। Demo donor-এর নিজের location না দিলে map-এ donor দেখাবে না।
  • Donor Interested → Seeker Select → Donor Confirm → I Have Donated → Seeker Confirm Blood Received। অন্য donor নিজের Not selected status দেখবে।
  • রক্ত না পেলে Record Not Received। Donation report থাকার পর এটি Disputed হয়; ভুল report হলে donor সংশোধন করতে পারে।
  • Map-এর রাস্তা দেখাতে internet লাগে। District এবং Zila একই ধাপ। পুরোনো custom address থাকলে নতুন dropdown দিয়ে update করুন।

৬. Reminder নিয়ে গুরুত্বপূর্ণ কথা

Default reminder 105 দিন পর in-app Alerts-এ আসে। এটি medical clearance নয়। XAMPP/PC বন্ধ থাকলে job চলবে না। No-visitor automation-এর জন্য bin/maintenance.php scheduler-এ দিতে হবে; README-তে Mac/Windows command আছে। Demo-তে Admin → System Settings → Run Due Jobs Now ব্যবহার করা যায়।

যদি error আসে

  • কোন folder চলছে বুঝতে browser-এর URL দেখুন—এই package-এর BloodBridge_BD path ব্যবহার করুন। পুরোনো setup page খুলবেন না।
  • Database connection error: Apache/MySQL status এবং config/database.local.php যাচাই করুন।
  • Setup error: database না মুছে Apache/PHP error log দেখুন। Exact error ও URL দিন।
  • Upload rejected: প্রকৃত JPG/PNG/PDF, maximum 2 MB এবং PHP-তে Fileinfo enabled থাকতে হবে।
  • Donor unavailable: health profile/consent/screening/last donation interval পরীক্ষা করুন। নিরাপত্তা বাধা bypass করে donation confirm করবেন না।

এই build কোনো real hospital accreditation, medical eligibility certificate, email/SMS delivery বা mobile app দাবি করে না। Real service চালুর আগে production/security/clinical review প্রয়োজন।
